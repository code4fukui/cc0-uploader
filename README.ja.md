# cc0-uploader

画像をアップロードし、CC0（パブリックドメイン）ライセンスで公開するためのシンプルなWebアプリケーションです。

## デモ

**[https://cc0.sabae.cc/](https://cc0.sabae.cc/)**

## 仕組み

ユーザーはインターフェース上で、1つ以上の画像ファイルを選択またはドラッグ＆ドロップできます。アップロードボタンをクリックすると、画像がサーバーに送信・保存され、即座にメインページのギャラリーに表示されます。

**重要:** アップロードされたすべての画像はCC0（パブリックドメイン）として扱われ、誰でも自由に利用できるようになります。パブリックドメインとして公開する権利を持つ画像のみをアップロードしてください。

ギャラリーには各画像のサムネイルが表示され、フルサイズ画像へのリンクになっています。各画像の下にあるテキストフィールドから、直接URLをコピーできます。

## 機能

- **シンプルなインターフェース**: ドラッグ＆ドロップまたはファイル選択で画像をアップロードできます。
- **CC0ライセンス**: 画像をパブリックドメインとして公開することに特化した設計です。
- **即時アクセス**: アップロードされた画像は、直接URL経由ですぐに利用可能になります。
- **画像ギャラリー**: アップロードされたすべての画像を新着順（逆時系列）で表示します。
- **自動リサイズ**: 画像は自動的に最大幅1220pxに縮小されます。
- **軽量なサーバー**: Denoで構築されており、URLベースのインポートを使用するためパッケージマネージャーは不要です。

## ローカルでの実行

### 要件

- [Deno](https://deno.land/) (v1.32+)

### 手順

1. リポジトリをクローンします:
    ```sh
    git clone https://github.com/code4fukui/cc0-uploader.git
    cd cc0-uploader
    ```

2. 必要な権限を付与してサーバーを実行します。オプションでポート番号を指定できます。
    ```sh
    # Run on the default port 8081
    deno run --allow-read --allow-write --allow-net server.js

    # Run on a custom port (e.g., 8000)
    deno run --allow-read --allow-write --allow-net server.js 8000
    ```

3. ブラウザを開き、`http://localhost:8081`（または指定したポート）にアクセスします。

## 技術的な詳細

- **アップロードエンドポイント**: `POST /api/upload`
    - サーバーは、CBORでエンコードされたバイナリ画像データの配列を受け取ります。
- **ファイルの保存場所**: `static/data/[YYYYMMDD]/[N].jpg`
    - 画像は日付名（例: `20231026`）のディレクトリに保存されます。
    - ファイル名には、その日の連番（例: `0.jpg`, `1.jpg`）が使用されます。
- **データマニフェスト**: `static/data/list.json`
    - すべてのアップロードを記録するJSONファイルです。各エントリは `day`、`fn`（ファイル名）、`dt`（ISO 8601タイムスタンプ）のフィールドを持つオブジェクトです。
    - **注意**: `static/data/` ディレクトリは `.gitignore` に含まれており、最初のファイルアップロード時に自動的に作成されます。
